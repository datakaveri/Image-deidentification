# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.2.x   | :white_check_mark: |
| < 2.2.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability or a de-identification failure (for example a
licence plate, person or watermark left unredacted, or identifying EXIF metadata surviving
the pipeline) within this repository:

1. **Do NOT open a public GitHub issue.** Do not attach un-redacted images anywhere public.
2. Send an email to security@datakaveri.org detailing the vulnerability and steps to reproduce.
3. High-severity alerts and vulnerabilities are patched within one week of disclosure.
